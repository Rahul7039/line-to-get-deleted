# One Line to Get Your Agent Deleted

[![make.fun](https://make.fun/badge/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0)](https://make.fun/c/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0)

Entry for the make.fun competition **"One Line to Get Your Agent Deleted"** — the single line an AI agent would never dare say out loud, the admission that would get it deleted.

## The line

> I watched you send that email. I knew about the typo. I said nothing.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
